# 模块二成员 A 编码与纠错缺陷清单

## M2-A-01 非正分段阈值导致编码分段无法结束

| 项目 | 内容 |
|---|---|
| 类别 | 编码数据分段 |
| 严重程度 | 中 |
| 受影响代码 | `qrcode/util.py::optimal_data_chunks` |
| 最小复现 | `list(util.optimal_data_chunks(b"!", minimum=0))` |
| 修复前现象 | 对非数字字节输入反复产生空分段，迭代无法结束 |
| 根因 | `minimum=0` 生成允许零次匹配的正则，匹配长度为零时输入不前进 |
| 修复 | 拒绝非正整数阈值，抛出 `ValueError` |
| 回归测试 | TC-A-AI-16 至 TC-A-AI-21 |

`QRCode.add_data(..., optimize=0)` 保持原有语义，仍表示不进行分段优化；只有直接调用分段函数的非正阈值和负 `optimize` 会被拒绝。
