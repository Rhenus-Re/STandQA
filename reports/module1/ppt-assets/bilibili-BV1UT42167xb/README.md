# 二维码生成链路 PPT 素材

本目录中的 PNG、SVG 和 ASCII 文件均由仓库当前的 `qrcode` 代码生成，输入固定为 `https://www.bilibili.com/video/BV1UT42167xb/?spm_id_from=333.337.search-card.all.click&vd_source=b9c708ab84f8ceb98f14f4d1bf5f3ad7`。`trace.json` 保存输入、编码模式、版本、掩码、最终码字和矩阵尺寸；`01-matrix-bits.txt` 保存不含静区的真实模块矩阵。

`06-styled-bilibili-qr.png` 为 PPT 使用的风格化版本：同一输入、H 级纠错、Version 11、61×61 模块、白色静区、深粉色圆角模块。

同一参数下另提供三种备选：`07-styled-gradient-purple-pink.png`（紫粉渐变圆角）、`08-styled-gapped-blue.png`（蓝色留白方块）和 `09-styled-circle-violet.png`（紫色圆点）；`10-styled-qr-options-preview.png` 为四种样式的预览图。
