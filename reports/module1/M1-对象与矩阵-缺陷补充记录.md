# 对象与矩阵缺陷补充记录

本记录补充对象与矩阵测试域的 B-04 缺陷证据。被测版本为 `python-qrcode v8.2`，执行环境为 Python 3.12.14。

## B-04：自动适配超出版本上限时抛出错误异常类型

| 项目 | 内容 |
|---|---|
| 类别 | 对象版本适配与异常行为 |
| 严重程度 | 中：调用者无法按 `DataOverflowError` 处理容量不足 |
| 回归用例 | `TC-B-13` |
| 受影响源码 | `qrcode/main.py::QRCode.best_fit` |
| 公开来源 | 上游 Issue [#322](https://github.com/lincolnloop/python-qrcode/issues/322) |
| 测试提交 | `b59786a` |
| 修复提交 | `fbcee7b` |

最小复现：

```python
qr = QRCode()
qr.add_data(b"A" * 5000)
qr.make()
```

修复前，自动适配查找得到的候选版本为 41。代码先把该值写入 `version` 属性，属性校验立即抛出：

```text
ValueError: Invalid version (was 41, expected 1 to 40)
```

但版本 41 在这里不是用户输入错误，而是“数据无法放入最大版本 40”的内部哨兵值；公开 API 应抛出 `DataOverflowError`，让调用者可与固定版本容量不足时保持一致地处理。

修复将候选版本保存在局部变量，先判断是否为 41；若是则抛出 `DataOverflowError`，否则再赋值给 `self.version`。修复后 `TC-B-13` 通过，5000 字节输入正确报告 `DataOverflowError`。
