## 4. AI 原始输出（摘要）

AI 生成 8 条用例：TC-M2-C-01 PilImage.save 的 kind 参数映射 PIL format（含 JPEG 分支）；
TC-C-AI-02 SVG width/height 与 viewBox 的 mm 换算（box_size 1/3/5）；TC-C-AI-03
SvgFragmentImage 无 XML 声明的片段输出；TC-C-AI-04 CLI --factory png/svg-fragment/svg-path
全后端输出矩阵；TC-C-AI-05 CLI --error-correction L/M/Q/H 值域与非法值；TC-C-AI-06
print_ascii 在 border=1/2/3 奇偶静区下的行数与行宽；TC-C-AI-07 print_ascii(tty=True) 的
ANSI 着色契约；TC-C-AI-08 CLI --factory 无效值错误处理矩阵。

缺陷定位：AI 指出 `console_scripts.main` 仅捕获 `ValueError`，`get_factory()` 内裸
`__import__` 与 `getattr` 对带点非法路径会抛出未捕获的 `ModuleNotFoundError` 或
`AttributeError` 原始 traceback；同类输入 `--factory foo`（无点）与 `--error-correction X`
均为 SystemExit 2 友好退出，行为不一致。建议在 try 块补充 `except (ImportError,
AttributeError)` 走 `raise_error()`。

## 5. 人工审核结论

| 用例 | 审核结论 | 理由 |
|---|---|---|
| TC-M2-C-01 | 修改后接受 | AI 初稿比照 PyPNG 预期 kind="JPEG" 抛 ValueError；人工运行发现 PilImage 不经 check_kind，实际产出真 JPEG。预期结果改为「JPEG 魔数 + PIL 重开识别为 JPEG」，并补充文件路径分支 |
| TC-C-AI-02 | 直接接受 | 换算公式 `pixel_size/10 mm` 明确，三组非默认 box_size 均经运行验证 |
| TC-C-AI-03 | 直接接受 | 片段后端（无 XML 声明、svg: 前缀命名空间）为模块一完全未覆盖的后端 |
| TC-C-AI-04 | 修改后接受 | AI 初稿仅测 png 与 svg-path，人工补充 svg-fragment 以覆盖片段后端的 CLI 链路 |
| TC-C-AI-05 | 直接接受 | L/M/Q/H 全值域逐一断言，非法值作为 CLI 参数校验的对照基线 |
| TC-C-AI-06 | 直接接受 | 奇偶静区边界行数公式 `ceil((modcount+2*border)/2)` 经 border=1/2/3 验证 |
| TC-C-AI-07 | 修改后接受 | AI 初稿断言每行均含背景码 48;5;232；人工比对源码发现末行（r=modcount+border-1）不写背景码，放宽为「前景码与重置码必有、背景码仅非末行」并保留末行反向断言 |
| TC-C-AI-08 | 修改后接受 | AI 初稿仅一个非法值场景且预期统一抛异常；人工扩展为四场景矩阵（合法快捷键/无点非法/带点非法模块/带点非法类名），运行中确认缺陷 M2-C-01 并改以修复后契约为预期 |
